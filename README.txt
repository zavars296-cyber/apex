Apex Home Renovations - ready-to-deploy static website

Deploy on Netlify: open https://app.netlify.com/drop and drag this whole folder
(or this ZIP) onto the page. Entry point: index.html.

Contents
- index.html   page with all HTML, CSS, JavaScript and fonts built in
- images/      local images (used when a stock photo can't load)
- favicon.svg  site icon
- netlify.toml optional Netlify settings (image caching)

Photos: the main photographs load from Pexels (images.pexels.com, free license).
If a photo can't load, the matching local image from images/ is shown instead.
The site also works offline by double-clicking index.html.
